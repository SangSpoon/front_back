# 🗺️ 지도가 안 뜨는 문제 해결 가이드

## 1. 브라우저 개발자 도구 확인

### 1.1 콘솔 오류 확인
1. **F12** 또는 **우클릭 → 검사** 클릭
2. **Console** 탭 확인
3. 빨간색 오류 메시지가 있는지 확인

### 1.2 네트워크 탭 확인
1. **Network** 탭 클릭
2. **dapi.kakao.com** 요청이 성공했는지 확인
3. **Status**가 200인지 확인

## 2. 카카오 개발자 콘솔 설정 확인

### 2.1 도메인 설정
1. [Kakao Developers](https://developers.kakao.com/) 접속
2. **내 애플리케이션** → 생성한 앱 선택
3. **플랫폼** → **Web** 설정
4. **사이트 도메인**에 추가:
   ```
   http://localhost:3000
   http://localhost:5173
   http://localhost:8080
   ```

### 2.2 JavaScript 키 확인
1. **앱 키** 탭에서 **JavaScript 키** 복사
2. `SiteMap.tsx`의 `apiKey` 변수와 일치하는지 확인

## 3. 코드 문제 확인

### 3.1 API 키 설정
```typescript
// SiteMap.tsx 파일에서
const apiKey = "26238f41ce94beb8c0d6d3d4cd3e26af";
```

### 3.2 스크립트 로드 확인
```typescript
script.src = `//dapi.kakao.com/v2/maps/sdk.js?appkey=${apiKey}&libraries=services`;
```

## 4. 일반적인 문제와 해결책

### 4.1 "지도를 불러올 수 없습니다" 오류
- **원인**: API 키 오류 또는 도메인 설정 문제
- **해결**: 카카오 개발자 콘솔에서 도메인 설정 확인

### 4.2 "지도 스크립트를 불러올 수 없습니다" 오류
- **원인**: 네트워크 문제 또는 스크립트 차단
- **해결**: 인터넷 연결 확인, 방화벽 설정 확인

### 4.3 지도는 뜨지만 마커가 안 뜸
- **원인**: 현장명 검색 실패
- **해결**: 현장명을 더 구체적으로 입력 (예: "서울시청" → "서울특별시청")

## 5. 테스트 방법

### 5.1 간단한 테스트
1. 현장 관리 페이지에서 **지도 아이콘** 클릭
2. 지도 페이지로 이동 확인
3. 로딩 스피너 표시 확인
4. 지도 또는 오류 메시지 표시 확인

### 5.2 브라우저별 테스트
- **Chrome**: 가장 안정적
- **Firefox**: 대부분 정상 작동
- **Safari**: 일부 기능 제한 가능
- **Edge**: Chrome과 동일

## 6. 대안 해결책

### 6.1 하드코딩 좌표 사용
```typescript
// 특정 현장의 좌표를 직접 설정
const siteCoordinates = {

  "현장2": { lat: 37.5519, lng: 126.9882 }
```

### 6.2 다른 지도 API 사용
- **네이버맵 API**: 한국 지도에 최적화
- **Google Maps API**: 전 세계 지도 지원
