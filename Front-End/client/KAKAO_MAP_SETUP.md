# 카카오맵 API 설정 가이드

## 1. 카카오맵 API 키 발급

### 1.1 카카오 개발자 계정 생성
1. [Kakao Developers](https://developers.kakao.com/) 접속
2. 카카오 계정으로 로그인
3. "내 애플리케이션" → "애플리케이션 추가하기" 클릭

### 1.2 애플리케이션 생성
1. **앱 이름**: "WaterSupply-Monitoring-System" (또는 원하는 이름)
2. **회사명**: 회사명 입력
3. **생성** 버튼 클릭

### 1.3 JavaScript 키 복사
1. 생성된 애플리케이션 선택
2. **앱 키** 탭에서 **JavaScript 키** 복사
3. 이 키를 `Front-End/client/pages/SiteMap.tsx` 파일의 `apiKey` 변수에 붙여넣기

## 3. 카카오맵 API 사용량

### 3.1 무료 사용량
- **일일 사용량**: 300,000회
- **월 사용량**: 9,000,000회
- **연 사용량**: 108,000,000회

### 3.2 과금 기준
- 무료 사용량 초과 시 1,000회당 1원
- 대부분의 경우 무료 사용량으로 충분

## 4. 주의사항

### 4.1 도메인 설정
- 카카오 개발자 콘솔에서 **플랫폼** → **Web** 설정
- **사이트 도메인**에 실제 서비스 도메인 추가
- 개발 환경: `http://localhost:3000` 추가
- 프로덕션: 실제 서비스 도메인 추가

### 4.2 API 키 보안
- API 키는 클라이언트 사이드에 노출되므로 보안에 주의
- 프로덕션 환경에서는 환경 변수 사용 권장

## 5. 테스트

### 5.1 지도 표시 확인
1. 현장 관리 페이지에서 지도 아이콘 클릭
2. 지도 페이지로 이동 확인
3. 현장 위치 마커 표시 확인

### 5.2 오류 발생 시
- 브라우저 개발자 도구 콘솔 확인
- API 키가 올바르게 설정되었는지 확인
- 도메인 설정이 올바른지 확인
